# Фотоформат

Статичний україномовний сайт для масової конвертації фото в JPG. Без залежностей, сервера, аналітики та зовнішніх запитів. Фотографії обробляються локально через Canvas.

## Стандартні налаштування
Коротша сторона фото менша за 1200 px: збільшити до 1200 px, довшу — пропорційно (округлення до цілого пікселя). Якщо коротша сторона вже 1200 px або більша, залишити розміри без змін. JPG, якість 100% за замовчуванням. Ручні режими доступні окремо.

## Можливості
- Вибір кількох файлів або перетягування.
- Власні розміри та готові пресети.
- Вписування в межі, центральне обрізання, точний розмір із полями.
- Якість JPG, колір фону, керування збільшенням.
- Окремі JPG або ZIP з усіма успішно обробленими фото.
- Помилка одного файлу не перериває партію.

## Запуск
Відкрийте `index.html` у сучасному браузері або запустіть локальний статичний сервер у цій папці.

## GitHub Pages
1. Завантажте `index.html`, `style.css`, `app.js` та `.nojekyll` у корінь потрібної гілки репозиторію.
2. У налаштуваннях репозиторію відкрийте **Pages**.
3. Виберіть **Deploy from a branch**, потрібну гілку та папку **/ (root)**, збережіть.
4. GitHub покаже адресу опублікованого сайту після розгортання.

## Обмеження
- Приймаються всі файли без відсікання за розширенням, зокрема JFIF/JIF/JFI, JPEG, PNG, WebP, BMP, GIF, AVIF, SVG. Фактичне декодування залежить від браузера; HEIC/HEIF, TIFF, RAW та інші спеціальні формати можуть бути недоступними — для них буде повідомлення про помилку. Анімація перетворюється на один статичний кадр.
- У режимі вписування вихідний розмір може бути меншим. Без збільшення маленькі фото збережуть свій розмір. Обрізання завжди заповнює точний розмір і за потреби збільшує фото.
- Ручні розміри: до 8192 px на сторону і до 32 мегапікселів. Автоматичний режим не зменшує фото: вихід до 32767 px на сторону та 100 мегапікселів; понад це — помилка, без прихованого зменшення. Реальний ліміт Canvas залежить від браузера. Великі партії залежать від доступної пам’яті пристрою.
- ZIP без додаткового стиснення, до 4 ГБ і 65535 файлів; JPG уже стиснений.
- Метадані оригіналу не переносяться. Це растрова браузерна конвертація, не інструмент професійного керування кольором.

## Швидка обробка в папці
Оранжева кнопка використовує File System Access API (Chrome/Edge на комп’ютері). Користувач вибирає папку з дозволом на запис, відмічає фото та запускає заміну. Використовуються поточні налаштування розміру, JPG-якості, яскравості, контрасту та захисту світлих ділянок.

- JPG перезаписуються під своєю назвою; інші формати стають однойменними `.jpg`. Префікс `gotovo_` залишається для звичайного завантаження/ZIP.
- Перед записом кожного результату оригінал копіюється до `_photoformat_originals/<дата-ідентифікатор>/` у вибраній папці. Для відновлення скопіюйте оригінал назад.
- Оригінал іншого формату прибирається з основної папки лише після успішного запису JPG. Якщо видалення заборонено, залишаються обидва файли з повідомленням.
- Збіг назв JPG пропускається; інші файли та вкладені папки не обробляються.
- Дозвіл запитується для папки, не для кожного фото. Браузер контролює збереження дозволу між сесіями.
- Для публікації також потрібен `quick-folder.js`.
